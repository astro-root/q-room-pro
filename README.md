# Q-Room Pro

競技クイズルームのブラウザーMVPです。現在は単一端末で司会と複数プレイヤーを操作する試作で、ルームコードを使った別端末参加・オンライン同期には対応していません。

## 起動

ES Modulesを使うため、`index.html`を直接開く代わりにリポジトリ直下で簡易HTTPサーバーを起動してください。

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。依存パッケージやビルド工程はありません。

## 操作

- ルーム作成から名前・ルール・プレイヤー名を設定します。
- ゲーム開始後、任意のプレイヤーボタンを押して回答者を決めます。
- 司会が正解/不正解を判定し、次の問題へ進行します。
- 問題は20秒で自動終了し、司会の「回答なし」操作でも次問へ進めます。
- 「プレイヤー画面」で大きな早押しボタンに切り替えられます。プレイヤー選択は同一端末の操作確認用です。
- PCでは `1`〜`9` キーでも対応するプレイヤーの早押しを再現できます。

ゲームルールと状態遷移は `src/domain.js` にあります。設計の詳細は `docs/PROJECT_SPEC.md`、`docs/ARCHITECTURE.md`、`docs/DOMAIN_MODEL.md`、`docs/TECH_STACK.md`、`docs/ROADMAP.md` を参照してください。
