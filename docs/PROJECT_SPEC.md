# Q-Room Pro 要件定義（MVP）

## プロダクト
競技クイズの出題・早押し・正誤判定・スコアをひとつのゲームルームで管理する。PCは司会とスコアボード、スマートフォンは大きく即応するプレイヤー操作を主眼にする。

## MVPの対象
- ブラウザー上でルームを作り、同一端末で司会・プレイヤー操作を試せる。
- ルーム名、プレイヤー名、7○3×または10by10を選ぶ。
- ゲーム開始、早押し、正誤判定、次問、終了、順位・得点・○×表示。
- 出題ごとの20秒カウントダウンと、司会による回答なし処理。
- タッチ端末で即時の押下表示と利用可能端末での短い振動を行う。
- 入力名をHTMLとして解釈せず、ゲーム状態は有効な遷移だけを受け付ける。

## MVP対象外
アカウント、複数端末間のルーム共有、サーバー同期、問題データベース、永続的な履歴、チャット、課金、ランキング、Bluetooth/Wi-Fi Direct、カスタムルール、ネイティブ配布。

## 画面
1. ホーム：ルーム作成への導線。
2. ルーム作成：名前、ルール、参加者名。
3. ルーム：ルームコード、現在の状態、司会操作、プレイヤー別早押しボタン、得点・○×。
4. プレイヤー画面：一人分の得点・○×と大型の早押し操作。MVP試作では同一ブラウザー内で司会画面と切り替える。
5. 結果：終了時に順位と各プレイヤーの記録。

## 受け入れ条件
- ルールを選んで複数プレイヤーのゲームを開始できる。
- 出題中のみ有効プレイヤーが早押しでき、先着一人だけが回答者となる。
- 司会の正誤判定が○×、得点、失格、終了判定へ反映される。
- 誤答時は誤答者を同じ問題の受付から外し、ほかに回答可能なプレイヤーがいれば受付を続ける。
- 7○または10○で勝者を確定する。7○3×では3×で失格とする。
- リセット後に初期状態へ戻る。

## 制約と品質
現在のMVPは単一ブラウザー内だけで動く。ルームコードは表示用であり、別端末からの参加や競技上の公平性を意味しない。ブラウザーの振動API、音声自動再生、全画面表示は端末・権限に左右される。サーバー時刻での同時押し裁定を提供しない。
